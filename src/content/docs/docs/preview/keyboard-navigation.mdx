title: Keyboard Navigation
description: Navigate between files in preview mode with keyboard shortcuts.
---

The Spacebar preview supports keyboard navigation so you can quickly scan through your files.

## Preview shortcuts

| Key | Action |
|---|---|
| **Space** | Open preview (when file selected) / Close preview (when open) |
| **Escape** | Close preview |
| **Left Arrow / Up Arrow** | Previous file in the list |
| **Right Arrow / Down Arrow** | Next file in the list |

## File list shortcuts

| Key | Action |
|---|---|
| **Up Arrow** | Select the previous file |
| **Down Arrow** | Select the next file |
| **Cmd+click** | Add a file to the selection (multi-select) |
| **Shift+click** | Select a range of files |

## Grid view shortcuts

In grid view, the same **Cmd+click** and **Shift+click** shortcuts work for multi-select. Double-click a thumbnail to open the file in its default application.

## Workflow

A typical preview workflow:

1. Search or filter to narrow your file list.
2. Click the first file to select it.
3. Press **Space** to open the preview.
4. Use **Left/Right** arrows to scan through files.
5. When you find what you need, press **Space** to close, then double-click to open.

This lets you review many files quickly without leaving MakerVault or opening each file individually.
