When you need to tag or assign a source to many files at once — like an entire bundle you just downloaded — MakerVault's bulk editing makes it fast.

## Selecting multiple files

| Action | Result |
|---|---|
| **Click** | Select a single file |
| **Cmd + Click** | Add/remove individual files from the selection |
| **Shift + Click** | Select a range of files from the last clicked file |

## The bulk action bar

When multiple files are selected, a bar appears at the bottom of the file list showing the number of selected files. Click the action you want to apply to all selected files at once.

### Applying a tag

1. Click **Tag** in the bulk bar.
2. Select an existing tag or type a name to create a new one.

### Applying a source

1. Click **Source** in the bulk bar.
2. Select a source, and optionally a bundle within that source.

### Assigning a machine

1. Click **Machine** in the bulk bar.
2. Select a machine to assign it to all selected files, or choose **Unassign** to clear the machine field.

See [Machines](/file-management/machines) for how to set up machines in Preferences.

All selected files are updated immediately.

## Common workflows

### Tagging a new bundle

1. Add the folder containing the bundle.
2. Filter by that folder in the sidebar.
3. Select all files (Cmd+A or Shift+click from first to last).
4. Use the bulk bar to apply tags like the material type or project category.

### Assigning a source to a bundle

1. Select all files from the bundle.
2. Click **Add**, choose **Source**, and pick the marketplace you purchased from.
3. Optionally select the specific bundle under that source.

### Organizing by category

1. Search for a file type (e.g., type "SVG" in search).
2. Select all matching files.
3. Apply a category tag.
