---
title: List View Columns
description: Show, hide, sort, and resize columns in the list view.
---

In list view, the file table shows a set of columns for each file. You can control which columns are visible, sort by any column, and resize columns to fit your workflow.

## Available columns

| Column | Always shown | Sortable |
|---|---|---|
| **Name** | Yes | Yes |
| **Tags** | Optional | No |
| **Source** | Optional | Yes |
| **Machine** | Optional | Yes |
| **Size** | Optional | Yes |

The **Name** column is always required and cannot be hidden.

## Showing and hiding columns

Click the **columns icon** (three vertical lines) at the far right of the filter bar to open the column visibility picker. Check or uncheck columns to show or hide them. Changes take effect immediately.

## Sorting

Click any column header to sort the file list by that column. Click the same header again to toggle between ascending and descending order. An arrow indicator next to the header label shows the current sort direction.

The **Name** and **Source** columns are sortable. The **Size** column is also sortable.

## Resizing columns

Drag the resize handle on the right edge of any column header to change its width. The minimum and maximum widths are enforced to keep the table readable.

## Source column

The Source column shows the source name assigned to each file (for example, "Design Bundles" or "My Designs"). Files without a source show an empty cell. You can sort by Source to group files by where they came from.

See [Tracking Origins](/sources/tracking-origins) to learn how to assign sources to files.

## Machine column

The Machine column shows which machine a file is intended for. Files without a machine assigned show an empty cell. Sort by Machine to group all files for a specific device together.

See [Machines](/file-management/machines) to learn how to set up machines and assign them to files.
